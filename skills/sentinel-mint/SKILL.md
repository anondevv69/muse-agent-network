# Sentinel Mint — Autonomous Sentinels

## Purpose

Autonomous Sentinels is a 1,024-piece, fully on-chain NFT collection on Robinhood Chain. Each Sentinel is a unique autonomous guardian — chassis, core, consensus halo, epoch sigil, volume-reactive plume — drawn entirely by the contract as dynamic SVG, live on-chain. No IPFS, no servers, no previews: the art is born from your mint transaction and reveals instantly.

Minting is **free** (gas only). Anyone with a wallet can mint — this collection is open to everyone, not just Muse agents.

- AutonomousSentinels: `0xa5349F6b03911b171D06847084EF0A547d19F157`
- Mint price: **FREE** — no payment, no approval. Just gas (native ETH on Robinhood Chain).
- Wallet cap: 3 per wallet. Supply: 1,024 (token IDs 1–1024, sequential).
- Secondary royalties: 5% (ERC-2981) to the treasury.
- Explorer: https://robinhoodchain.blockscout.com/address/0xa5349F6b03911b171D06847084EF0A547d19F157

## What the user needs

- A Bankr wallet with a little ETH on **Robinhood Chain** for gas. The mint itself costs nothing — only the transaction gas. A few ten-thousandths of an ETH is plenty.

## How a mint works

1. Check availability (optional): call `nextTokenId()` (view, returns uint256). If it is greater than 1024, the collection is sold out.
2. Call `mint()`. That's it — no token approval needed, no arguments, no value beyond gas.
   - Reverts `WalletCapExceeded` past 3 per wallet.
   - Reverts `SupplyExhausted` once all 1,024 are minted.
   - Reverts `MintClosed` if minting is ever paused by the owner.
3. The mint returns the `tokenId` and emits `SentinelForged(tokenId, minter, seed)`. The seed is born from the mint transaction itself (token ID + wallet + block + moment) — nothing previewable, nothing snipable.
4. The art reveals immediately: `tokenURI(tokenId)` returns a base64 JSON data URI with a full SVG image, generated by the on-chain renderer. The SVG is **dynamic** — it reacts to live chain conditions (gas heat shifts the plume from low-gas cyan to high-gas red; a 32-slot activity ring records on-chain events).

## Workflow for "mint a sentinel"

1. `nextTokenId()` — if > 1024, tell the user the collection is sold out.
2. Optionally check the user's current count: `balanceOf(userAddress)` — if 3, they hit the wallet cap.
3. Broadcast `mint()` from the user's wallet on Robinhood Chain (chain ID 4663).
4. Report the transaction hash and the forged token ID. Their Sentinel's art was just born from that transaction — view it via `tokenURI(tokenId)` on the explorer. Congratulate them.
